Quick Start Guide

Get up and running with DevDocs in minutes. This guide will walk you through installation, configuration, and your first deployment.

Prerequisites

Before you begin, ensure you have the following installed on your system:

  • Node.js 18.0 or later
  • A package manager (npm, yarn, or pnpm)
  • Git for version control
info

Important Note

We strongly recommend using pnpm for faster installations and better workspace management.

Installation

Initialize a new project using our CLI tool. This will scaffold the basic directory structure.

npx create-devdocs-app@latest my-docs
cd my-docs
pnpm install

Configuration

Customize your documentation site by editing the devdocs.config.js file.

// devdocs.config.js
export default {
  title: 'My Project Docs',
  theme: 'dark',
  navigation: [
    { title: 'Guide', path: '/guide' },
    { title: 'API', path: '/api' }
  ]
}

API Integration

Connect your backend services using our robust client.

GET /v1/projects/{id}
arrow_forward

Retrieves detailed information about a specific project.
